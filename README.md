# Basketball Score Counter

> **Status:** introductory JavaScript learning project.

A small two-team basketball score counter built to practice DOM manipulation, event handling, and responsive interface styling.

## Features

- Separate home and guest score displays
- One-, two-, and three-point controls
- New-game reset
- Lightweight browser interface with no backend

## Technology stack

HTML, CSS, JavaScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Scope and limitations

This repository is intentionally presented as a learning exercise. It does not include score persistence, game-clock logic, advanced basketball rules, or automated tests.
